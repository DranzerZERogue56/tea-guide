- blacktea and english-breakfast point to the same Adagio product (English Breakfast). The "Black Tea" entry is generic, so this is a stand-in.
- lychee-green and rose-green both point to Adagio Lychee Rose Green (same price). No separate rose green tea was found.

- apple-green is Adagio Autumn Mist (smoky gunpowder with apple and rose hips). OK but not a plain apple green tea.
- korean-green: the old link was Adagio Jade Snail (a Chinese tea). Now Harney Jeju Sejak (Korea, Jeju island), not Boseong.
- ilam-black: Upton Siddha Devi Estate Nepal, the only Nepal tea found whose page names Ilam. java-black: Upton Java BOP Blend (a blend, not a single estate).
- moonlight-white (Davidson's) and yunnan-white (Yunnan Sourcing Yue Guang Bai) are the same style of tea (Moonlight White).
- yunnan-ancient: Yunnan Sourcing Old Varietal "Lao Shu" Dian Hong from Feng Qing (Lincang). Not marked "ancient tree" exactly.
- jin-xuan, masala-chai, yerbamate: the old Adagio image URL was dead, new one is the og:image from the product page.
- ceylon-white: the old Harney link was dead. Upton Ceylon Silver Tips White Tea is a small 30g pack at $38.50, so it costs far more per gram than most entries.
- tulsi (40g for $19.75), tieguanyin and others use small packs, so check "price vs size" if you compare vendors.
- Unit size styles: Upton and Rishi sell in grams, so those entries read like "125g loose packet" instead of an ounce size.
- Sold with a year or season in the name (Yunnan Sourcing, Rishi Shincha): the listed variant is the Spring 2026 / current one, so it may change next season.
